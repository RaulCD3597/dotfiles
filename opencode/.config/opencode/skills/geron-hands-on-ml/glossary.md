# Glossary: Hands-on Machine Learning

**Accuracy** — The ratio of correct predictions to the total number of instances. (Ch 1)

**Activation Function** — A function (like ReLU or Sigmoid) applied to a neuron's output to introduce nonlinearity. (Ch 10)

**AdaBoost** — Adaptive Boosting; a sequential ensemble method that increases the weight of misclassified instances. (Ch 7)

**Adam** — Adaptive Moment Estimation; an optimizer that combines momentum and RMSProp. (Ch 11)

**Attention** — A mechanism that allows a model to focus on specific parts of the input sequence. (Ch 16)

**Autoencoder** — A neural network trained to reconstruct its own input, used for compression and feature extraction. (Ch 17)

**Backpropagation** — The standard algorithm for training neural networks using the chain rule to compute gradients. (Ch 10)

**Bagging** — Bootstrap Aggregating; training multiple models on random subsets of data with replacement. (Ch 7)

**Batch Normalization** — A technique to normalize layer inputs, reducing internal covariate shift and speeding up training. (Ch 11)

**Bias** — Error due to incorrect assumptions in the learning algorithm (leads to underfitting). (Ch 4)

**CNN (Convolutional Neural Network)** — A type of neural network specialized for processing grid-like data, such as images. (Ch 14)

**Confusion Matrix** — A table used to evaluate classification performance by showing true/false positives and negatives. (Ch 3)

**Curse of Dimensionality** — The phenomenon where high-dimensional data becomes sparse, making it hard to find patterns. (Ch 8)

**DBSCAN** — A density-based clustering algorithm that can find clusters of any shape and is robust to outliers. (Ch 9)

**Deep Learning** — A subfield of ML based on artificial neural networks with many hidden layers. (Ch 10)

**Dropout** — A regularization technique where neurons are randomly "dropped" during training. (Ch 11)

**DQN (Deep Q-Network)** — A reinforcement learning agent that uses a DNN to approximate Q-values. (Ch 18)

**Early Stopping** — Stopping training when performance on a validation set stops improving. (Ch 4)

**Embedding** — A low-dimensional, dense vector representation of a categorical variable or word. (Ch 13)

**F1 Score** — The harmonic mean of precision and recall. (Ch 3)

**Feature Engineering** — The process of using domain knowledge to create features that make ML algorithms work better. (Ch 1)

**GAN (Generative Adversarial Network)** — A system of two networks (Generator and Discriminator) competing to produce realistic data. (Ch 17)

**Gini Impurity** — A measure of how often a randomly chosen element from a set would be incorrectly labeled. (Ch 6)

**Gradient Descent** — An iterative optimization algorithm for finding the minimum of a cost function. (Ch 4)

**Hyperparameter** — A parameter set before the learning process begins (e.g., learning rate). (Ch 1)

**Inertia** — The sum of squared distances of samples to their closest cluster center in k-means. (Ch 9)

**k-means** — A popular clustering algorithm that partitions data into k groups based on distance to centroids. (Ch 9)

**Kernel Trick** — A method to operate in high-dimensional space without ever computing the coordinates of the data in that space. (Ch 5)

**LSTM (Long Short-Term Memory)** — A type of RNN cell designed to avoid the vanishing gradient problem. (Ch 15)

**MAE (Mean Absolute Error)** — The average of the absolute differences between predictions and actual values. (Ch 2)

**MSE (Mean Squared Error)** — The average of the squares of the errors. (Ch 2)

**Overfitting** — When a model performs well on training data but poorly on unseen data. (Ch 1)

**PCA (Principal Component Analysis)** — A linear dimensionality reduction technique that preserves maximum variance. (Ch 8)

**Precision** — The accuracy of positive predictions. (Ch 3)

**Recall** — The ratio of positive instances that were correctly detected. (Ch 3)

**Regularization** — Techniques used to prevent overfitting by penalizing large weights (e.g., L1, L2). (Ch 4)

**Reinforcement Learning** — An area of ML where an agent learns to take actions in an environment to maximize rewards. (Ch 18)

**RMSE (Root Mean Square Error)** — The square root of the MSE; a standard metric for regression. (Ch 2)

**RNN (Recurrent Neural Network)** — A type of neural network for processing sequential data. (Ch 15)

**Softmax** — A function that turns a vector of scores into a probability distribution. (Ch 4)

**SVM (Support Vector Machine)** — A powerful model that finds the widest possible margin between classes. (Ch 5)

**TFRecord** — A binary storage format for TensorFlow data. (Ch 13)

**Transformer** — A state-of-the-art NLP architecture based entirely on attention mechanisms. (Ch 16)

**Underfitting** — When a model is too simple to capture the underlying structure of the data. (Ch 1)

**Variance** — Error due to the model's sensitivity to small fluctuations in the training set (leads to overfitting). (Ch 4)
