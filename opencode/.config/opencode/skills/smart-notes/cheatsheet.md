# Cheatsheet: How to Take Smart Notes

## The Four Types of Notes
| Type | Purpose | Lifecycle |
|---|---|---|
| **Fleeting** | Catching ideas quickly | Process & Discard (24-48h) |
| **Literature** | Capturing author's gist + citation | Keep in Reference Archive |
| **Permanent** | Building your external brain | Keep Forever in Slip-box |
| **Project** | Organizing a specific manuscript | Discard/Archive after project |

## The Permanent Note Checklist
- [ ] Is it written in my own words? (No raw quotes)
- [ ] Does it contain exactly one idea?
- [ ] Can it be understood without the original context?
- [ ] Does it link to at least one other note?
- [ ] Does it specify its source (citation)?

## Workflow Comparison
| Traditional Writing | Smart Note-Taking |
|---|---|
| Top-Down (Pick topic first) | Bottom-Up (Topic emerges from notes) |
| Linear (Read -> Think -> Write) | Circular (Writing is the medium of all) |
| Category-based (Folders) | Connection-based (Links) |
| Brainstorming (Vacuum) | Slip-box-storming (Material-rich) |
| Willpower-driven | Workflow-driven |

## Quick Rules
1. **Standardize**: One format, one system.
2. **Atomize**: One idea per note.
3. **Connect**: A note without a link is lost.
4. **Translate**: If you can't explain it simply, you don't understand it.
5. **Separate**: Read now, process later, draft even later.

## Critical Questions to Ask Every Note
- "What does this mean for [X]?"
- "What is the difference between [A] and [B]?"
- "How does this support or contradict [C]?"
- "What is the broader principle here?"
