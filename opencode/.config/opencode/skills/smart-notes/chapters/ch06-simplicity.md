# Chapter 6: Simplicity Is Paramount

## Core Idea
The power of a system comes from its internal complexity, which can only grow if the external structure is kept radically simple and standardized.

## Frameworks Introduced
- **The Standardization Principle**: Use one format (e.g., plain text or A6 slips) and one workflow for all types of ideas.
- **Re-specification**: Converting an idea from its original context (a book) into a new, standardized context (the slip-box).

## Key Concepts
- **Cognitive Resources**: Standardization saves mental energy for the content of the notes rather than the organization.
- **The Paradox of Choice**: Too many tools or formats lead to decision fatigue and friction.

## Mental Models
- **Binary Code / Alphabet**: Systems with very few elements (0/1 or 26 letters) allow for the highest level of complexity in their combinations.
- **The Container**: A standardized note is like a shipping container; it can be handled the same way regardless of what is inside.

## Anti-patterns
- **Using Multiple Apps/Notebooks**: Distributing ideas across different systems makes it impossible to see connections.
- **Over-Categorization**: Creating complex tagging systems or nested folders.

## Key Takeaways
1. Less choice is often better for creativity.
2. Restricting the space for a note (e.g., one screen, one A6 card) forces precision.
3. The system should be "invisible" so you can focus on the thinking.
