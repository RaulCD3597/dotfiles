# Chapter 14: Make It a Habit

## Core Idea
The Zettelkasten system only works if it becomes an automatic habit. The goal is to reach a state where you don't have to "think" about the system, only the content.

## Frameworks Introduced
- **The Habit Loop**: Trigger (reading/thinking) -> Action (taking a note) -> Reward (seeing the box grow/finding a connection).
- **The Implementation Intention**: "If I read an interesting article, then I will write at least one literature note and one permanent note."

## Key Concepts
- **Friction**: The enemy of habits. Minimize the steps needed to capture and file notes.
- **Routines**: Simple, repeatable tasks that can become automatic (e.g., daily processing of fleeting notes).
- **Civilization Progress**: (Whitehead) Advancing by increasing the number of operations we can perform without thinking.

## Mental Models
- **Slow and Steady**: It's better to write 3 notes every day than 50 notes once a month.
- **The Investment Mindset**: Every note is a deposit into a high-yield account of ideas.

## Anti-patterns
- **Setting Unrealistic Goals**: Trying to "catch up" on months of reading in one day.
- **Complex Setups**: Spending more time tweaking the software than writing the notes.

## Key Takeaways
1. Focus on the process, not the outcome.
2. The system should be so simple that you have no excuse not to use it.
3. Trust that the results will follow if you stick to the daily routine.
4. "I'll do it later" is the enemy of the slip-box.
